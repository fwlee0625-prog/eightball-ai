# 项目文档

本目录存放研发规划、架构决策、数据契约草案、操作说明、测试标准和技术参考。

## 目录

- plan：研发路线、需求边界、系统架构、阶段实施、数据与接口、测试验收和参考资料。
- milestones：按里程碑 / M 保存验证提示词，并在每条提示词下记录实际验证结果；Codex 的“继续验证”入口见 `milestones/README.md`。
- verification：历史本地验证清单与结果归档；新一轮验证日志写入对应的 M 文档。

## 文档状态约定

- **规划中：** 预期设计或未来任务，尚未在代码中实现。
- **已实现：** 仓库中存在对应代码。
- **已验证：** 通过明确的测试或实验，并有可复现的结果。
- **已发布：** 已按发布流程部署或交付。

不要将“规划中”文档中的接口示例写成当前已经可用的 API。涉及外部库版本或官方规则时，记录来源、核对日期和适用范围。代码变更影响接口、运行方式或验收标准时，应同步更新文档。
