# 项目文档

本目录存放研发规划、架构决策、数据契约草案、操作说明、测试标准和技术参考。

## 目录

- plan：研发路线、需求边界、系统架构、阶段实施、数据与接口、测试验收和参考资料。
- [第一里程碑](第一里程碑/)：每个拆分项 M 一个文件，按开发段保存验证提示词，日志紧跟对应提示词。
- [第二里程碑](第二里程碑/)：第二里程碑的拆分项目录，具体任务待确定；后续里程碑按相同结构建立。
- “继续验证”按里程碑目录及 M 定位最新提示词，规则见根目录 AGENTS.md。
- verification：历史本地验证清单与结果记录；后续验证提示词和日志写入对应里程碑文件。

## 文档状态约定

- **规划中：** 预期设计或未来任务，尚未在代码中实现。
- **已实现：** 仓库中存在对应代码。
- **已验证：** 通过明确的测试或实验，并有可复现的结果。
- **已发布：** 已按发布流程部署或交付。

不要将“规划中”文档中的接口示例写成当前已经可用的 API。涉及外部库版本或官方规则时，记录来源、核对日期和适用范围。代码变更影响接口、运行方式或验收标准时，应同步更新文档。
