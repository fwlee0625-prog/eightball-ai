# M2.5 轨迹与事件输出

2026-11-02（Asia/Shanghai）

## 本轮内容

- `trajectory.py` 将 `SimulationResult` 导出为 JSON 可序列化字典。
- 每帧球 ID 升序排列，球坐标使用 mm，时间使用 s，耗时使用 ms。
- 事件保留事件类型、事件时间和球 ID；不假设 Pooltool 事件名称。
- 允许球在后续帧消失（例如未来入袋），禁止凭空出现新球或消失后重现。
- `sample_frame_at` 返回不晚于请求时间的最新离散帧，不做插值、不生成伪造运动。
- 当前为内部 Python 输出格式，尚未发布跨语言 JSON Schema 或前端播放器协议；不声称实际物理轨迹已接通。
