# 产品目标和需求边界

## 目标场景
中式八球，一桌一屏；视觉系统提供球静止时的坐标、球号与台面校准信息。输出一杆建议以及会流式衔接播放的清台演示。用户真人击球，不控制球杆。

## P0（首版必须）
1. 输入合法球局：桌面边界、袋口、0~15 球坐标、花色归属、轮次、开球/自由球等规则状态。
2. 校验观测：球重叠/丢失、在台边界、静止判定、球号置信度。
3. 一秒目标内先返回可执行的下一杆建议：目标球/袋口、瞄准方向、力度参数、杆法及预计白球落点，无法确定时明确降级。
4. 候选要处理角度误差、力度误差、人类击球难度、犯规风险；防守作为合法候选。
5. 多杆规划、逐段推送、动画连续衔接；规划不出来时真实显示等待。
6. 新真实状态到达立即创建新的 state_version，旧版本路线失效。

## P1
真人能力档位（新手/进阶/高手）、不同设备桌参数、职业球员专家讲解整理、机器学习训练、路线的可解释性。

## 非功能性目标
- 下一杆服务目标 p95≤1000ms：需明确起点（前端收到稳定球局并提交请求）与终点（前端收到可显示推荐），另测视觉采集到显示的端到端 p95。
- 全局清台耗时为软目标；允许边播边算，但必须有版本一致性和缓冲。
- 错误优先安全降级：球局无效、规则未知、超时均返回不可推荐原因而不是编造杆法。
- 运动预测显示置信范围；球号识别或杆法不确定时不得伪装高精度。

## 规则与合规
中式八球赛事规则可能随赛事及组织变化，必须把赛事所采用的正式规则版本、自由球、击打次序、黑八、犯规、防守等写成可配置规则集，并以赛事官方文本核对后发布；不可直接把美式八球规则当成中式八球。
公司数据必须先取得授权，明确训练用途、保留期限、影像/音频肖像授权和数据出境约束。

## 验收场景
开球后花色未确定、花色确定、只剩黑八、有障碍球、只能碰库、防守更优、可能犯规、球号缺失、真实击球偏离动画轨迹、多人并行请求等。
