## 安装建议（不是锁定版本）
首选 Python 3.11 或 3.12 作为初始验证候选，先单独安装 Pooltool 跑通官方例子后，再冻结精确版本；这属于**兼容性降低风险的工程建议**而非全库兼容保证。

```bash
python -m venv .venv
# 激活虚拟环境后，按照操作系统的官方要求安装
python -m pip install pooltool-billiards
python -c "import pooltool; print(pooltool.__version__)"
```
Windows/Linux 如遇 Panda3D 依赖问题，参考安装页附加 `--extra-index-url https://archive.panda3d.org/`，不要未理解时全局添加第三方源。

## 每次依赖升级时的检查
1. 记录升级前版本和官方 release notes；更新锁文件。
2. 运行最小物理示例、固定轨迹测试、所有 API 和 WebSocket 集成测试。
3. 运行固定球局基准并对比结果漂移与延迟。
4. 如有差异先定位，不直接上线。
