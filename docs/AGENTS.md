# 文档编写要求

本规则适用于 docs，并继承根目录 AGENTS.md。

- 面向本项目的主要读者使用中文说明；代码标识符、路径和官方 API 名称保持原文。
- 明确区分规划中、已实现、已验证和已发布，不能用未来时目标描述当前功能。
- 记录假设、限制、依赖、输入 / 输出、失败路径、验证方式和相关文档链接。
- 内部链接使用相对路径，修改或移动文件后检查链接目标。
- 外部技术信息尽量引用官方文档；写明核对日期和版本范围，避免把单次浏览结果当成永久事实。
- 规则、Schema、坐标系、单位、事件字段和验收指标必须与代码及测试保持一致。
- 不承诺未经测量的性能、清台率或职业水平。
- 文档变更后检查 README 导航、目录名、命令和示例是否与当前仓库一致。
