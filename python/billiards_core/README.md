# Billiards Core（台球领域核心）

## 状态

规划中。当前仓库尚无 Python 核心包。该目录将承载可独立测试、可复现的规则与决策领域逻辑。

## 职责

- 规则集与球局合法性校验。
- 球桌几何、目标球 / 袋口候选生成和障碍检测。
- 物理仿真器适配与轨迹 / 停位预测。
- 候选评分、执行难度与风险评估。
- 在计算预算内执行下一杆推荐与多杆规划。

## 设计原则

优先实现清晰的领域接口，再接入真实仿真器。规则、几何和评分应尽可能独立于 Web 框架；仿真器通过适配层隔离第三方 API。规划结果必须能追溯到输入球局、规则版本、物理参数和模型版本。

docs/plan/01_需求与架构/系统架构与启动.md 中的接口名称是自定义设计提案，不代表 Pooltool 已提供这些方法。

## 验收方向

使用固定合成球局测试直球、切球、碰库、遮挡、犯规风险和异常坐标；记录确定性、预测误差、合法推荐率和运行耗时。任何高精度或职业级结论都需要独立实测。
