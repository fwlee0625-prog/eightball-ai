# Billiards ML（机器学习与策略）

## 状态

规划中。当前仓库尚无训练代码、数据集管线或已发布模型。

## 职责

- 整理经授权的球局、轨迹、专家意图和实际结果数据。
- 建立可复现的数据切分、特征编码、模仿学习和强化学习实验。
- 训练、评估、导出模型权重与配置，并提供推理适配接口。
- 比较学习策略与规则 / 搜索基线，判断是否有真实增益。

## 关键原则

学习模型用于生成或排序候选，不取代规则引擎的合法性校验。训练与评测必须隔离，避免同一球员、同一局或相邻帧泄漏到测试集。XY 轨迹和主观口述不足以唯一确定所有杆法、旋转和真实速度，缺失标签不能靠模型或脚本伪造。

训练命令、依赖和模型格式在模块实现时再确定；不要提前声称存在可用权重或在线推理服务。
