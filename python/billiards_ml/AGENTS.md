# Billiards ML 开发要求

本规则适用于 python/billiards_ml，并继承根目录 AGENTS.md。

## 数据治理

- 只使用合成数据或明确获准用于该训练目的的数据。
- 记录数据来源、许可范围、处理步骤、Schema 版本和数据快照标识。
- 切分优先按球员、球桌、比赛日期或完整球局分组，避免相邻帧、同一杆或同一局泄漏到训练和测试集合。
- 不把“轻杆”“五成力”等主观语言当作精确速度标签；未知字段保持未知。

## 实验可复现性

- 固定并记录随机种子、依赖版本、超参数、数据快照、代码提交和模型版本。
- 保存训练曲线、验证指标、独立测试指标、基线对比和失败案例。
- 使用独立测试集和多个随机种子评估泛化，不只报告最佳一次结果。
- 记录模型适用范围、已知偏差和回滚版本。

## 在线策略边界

- 训练只能通过离线任务执行，不得阻塞 API 在线请求。
- 策略输出是候选或评分，必须由 billiards_core 的规则和安全检查筛选。
- 物理仿真误差较大时，不得以强化学习得分掩盖环境偏差。
- 不在没有真实或独立验证的情况下声称职业级表现。
