# 离线脚本开发要求

本规则适用于 scripts，并继承根目录 AGENTS.md。

- 每个脚本都要说明输入、输出、依赖、示例命令和失败行为。
- 对路径、数据集、参数和输出位置使用显式命令行参数；避免隐式读取开发者本机目录。
- 默认不覆盖原始数据。转换、清洗和校准结果写到单独输出目录，并保留来源与版本信息。
- 适合重复运行的脚本应尽可能幂等；随机过程必须接受并记录 seed。
- 错误输入应返回非零退出码和可理解的诊断；不得静默丢弃异常球局。
- 日志不得输出密钥、个人身份信息或未授权原始内容。
- 产出的报告应记录代码版本、Schema 版本、数据快照、参数、样本数和指标定义。
- 脚本应使用共享契约和核心包，不复制规则、仿真或评分算法。
