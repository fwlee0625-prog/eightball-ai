# Sample Data（样例数据）

## 状态

规划中。当前仓库没有提交球局样例数据。

## 允许的数据

- 人工合成、可重复生成的演示球局。
- 明确授权用于本项目、已按许可要求脱敏的最小样例。

## 不允许的数据

- 未获授权的比赛视频、音频或球员数据。
- 含个人身份信息、访问令牌、私人链接或其他敏感信息的数据。
- 未说明来源、许可和用途的第三方数据。

每份样例都应记录 Schema 版本、坐标系与单位、规则版本、数据类型（synthetic / authorized）、来源说明、许可范围和脱敏状态。样例只用于测试与演示，不应被误认为具有统计代表性的训练集或职业水平基准。
