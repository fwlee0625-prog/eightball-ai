# 样例数据目录要求

本规则适用于 data/samples，并继承根目录 AGENTS.md。

- 优先使用可复现的合成球局；只有明确获得授权并完成必要脱敏后才能加入真实样例。
- 不提交原始视频 / 音频、球员姓名、可识别身份、私人元数据、密钥或访问凭据。
- 每个样例都应有来源和许可说明，并标记 synthetic 或 authorized。
- 不覆盖原始样例；数据转换写到单独目录并保留版本和生成步骤。
- 样例需符合正式 Schema；如果 Schema 仍处于草案阶段，明确标记草案版本。
- 不要把少量演示样例当作有代表性的训练数据或评测证据。
- 提交前检查 Git diff，确认没有误带大文件、个人信息或未授权内容。
