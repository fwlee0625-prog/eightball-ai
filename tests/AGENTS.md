# 测试开发要求

本规则适用于 tests，并继承根目录 AGENTS.md。

- 测试必须对应明确行为或风险，避免只为覆盖率编写无意义断言。
- 每个关键模块至少覆盖正常、边界、非法输入 / 失败路径。
- 规则测试要覆盖所选规则版本和容易混淆的中式八球场景。
- 仿真 / 搜索使用固定合成样例、显式物理参数和固定随机种子；需要统计实验时报告重复次数和区间。
- 契约变更需验证有效、边界、缺字段、错误单位和不兼容版本样例。
- 流式集成测试需覆盖重复、乱序、取消、断连重连、旧 state_version 和 sequence 不连续。
- 不依赖外部网络、真实比赛数据或开发者个人环境才能通过普通单元测试。
- 避免时间敏感、随机不稳定或依赖真实模型训练的脆弱断言；慢速基准应与快速测试分开。
- 修复缺陷时先添加能复现问题的测试，再修复实现。
